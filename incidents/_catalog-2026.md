Dates, durations and numbers are as the source states them. Where sources disagree, the row says so. Underscore prefix = never published.

URL check: HTTP code from curl with a browser UA, plus a WebFetch read of the content. "403 (bot wall)" means curl and WebFetch were blocked, so the content was confirmed through search-indexed text and the press that quotes it.
